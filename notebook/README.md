# Research Notebooks

## `storyteller.ipynb`
An interactive research and experimentation Jupyter notebook demonstrating:
- Early prototype experimentation on Google Colab.
- Tokenization inspection using SentencePiece vs custom BPE.
- RoPE attention layer verification.
- Smoke generation runs for Amharic prompt completion.

For full reproducible terminal execution and production inference, refer to `scripts/reproduce_all.py` and `src/app/server.py`.
